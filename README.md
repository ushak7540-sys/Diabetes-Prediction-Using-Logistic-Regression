# Diabetes Prediction Using Logistic Regression

## Project Description
This project predicts whether a person is likely to have diabetes using Machine Learning.

## Algorithm Used
- Logistic Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Pima Indians Diabetes Dataset.

## Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Perform data cleaning and preprocessing.
4. Visualize the data.
5. Split the dataset into training and testing sets.
6. Train the Logistic Regression model.
7. Evaluate model performance.
8. Save the trained model.

## Model Performance
- Training Accuracy: 76.22%
- Testing Accuracy: 74.03%

## Files Included
- `Diabetes_Prediction_Logistic_Regression.ipynb` – Project notebook
- `diabetes (1).csv` – Dataset
- `Diabetes_Prediction_Project_Report.pdf` – Project report

## Conclusion
The project demonstrates how Logistic Regression can be used for diabetes prediction using patient health data.

**Note:** This project is for educational purposes only and is not a medical diagnostic tool.
